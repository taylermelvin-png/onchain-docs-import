# Charts

The Charts workspace (find it in the navigation menu) puts up to **six live token charts** on one screen — a multi-chart view for watching a basket of tokens at once.

## Building a workspace

* **Add charts** — search any token on any supported chain; each chart is a full live chart.
* **Arrange** — drag and resize charts on the grid until the layout fits your screen.
* **Save** — name the workspace and keep up to **five saved workspaces**, switchable from the Saved tab. They sync with your account.
* **Share** — the entire layout is encoded in the page URL, so copying the link shares your exact workspace with anyone.

**Reset** returns you to a single default chart when you want to start fresh.

***

{% hint style="info" %}
Charts is a watching surface — click through any chart to the token's full trading page when you're ready to act.
